# logs-archive-tool
This is my first tool aim at compressing them and storing them in a new directory. The tool runs from the command line, accepts the log directory as an argument, compresses the logs, and stores them in a new directory.
//CLI
log-archive <log-directory>

If my script has any errors, feel free to contact me, I'm eager to hear suggestion.

I got the ideas and requirements of the project from roadmap, here is the link:
https://roadmap.sh/projects/log-archive-tool
