# server-performance-stats
This is my small shell script used to track the status of:
 - Total CPU usage
 - Total memory usage (Free vs Used including percentage)
 - Total disk usage (Free vs Used including percentage)
 - Top 5 processes by CPU usage and Memory usage
 - OS stats(hostname, versions, architecture, kernel, ...)

If my script has any errors, feel free to contact me, I'm eager to hear suggestions.

I got the ideas and requirements of the project from roadmap, here is the link:
https://roadmap.sh/projects/server-stats
